# Vanashree — coverage core and UI presentation

**Mission:** inspect configured workspace for requirement/code/test evidence, report honest coverage, and render canonical HTTP responses. Native VERITY chat is powered by Atharv's Cline SDK agent; Vanashree owns its UI presentation, not an agent or retrieval engine. **Branch:** `feature/vanashree-coverage-ui`, created by Vanashree from `integration/verity-v1` at checkpoint 0. **Owned:** `verity/coverage/**`, `sdk-ui/frontend/**`, focused coverage/UI tests and workspace fixtures. Coverage core and UI presentation remain separate packages and PRs.

## Git / PR / Merge Schedule

All PRs target `integration/verity-v1`; titles `verity(coverage|ui): <scope> [PR-N#|PR-U#]`. Atharv merges after adjacent reviewer approval. Prefer implementation + tests commits or one atomic commit. Each gate: owned paths only, focused tests, relevant `$defs`, no frozen-contract changes; real integration requires upstream PRs and no mock in production route. After the exact last step in each PR row and its tests pass, push the feature branch, open that PR, and post the test result/fixture/commit hash. Keep the same branch for the next owned PR; after a merge, update it from `integration/verity-v1` only at the pull gates below.

| PR | Open exactly after | Reviewer | Merge owner | Gate; work while reviewed | Merge unblocks |
|---|---|---|---|---|---|
