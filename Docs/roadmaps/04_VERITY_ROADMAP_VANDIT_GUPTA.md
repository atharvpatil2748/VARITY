# Vandit Gupta — MCP, HTTP and external Cline

**Mission:** expose one `VerityService` through the frozen four MCP tools and `/api/v1` routes, then prove an external Cline client calls the MCP server. For native VERITY chat, HTTP routes delegate to Atharv's Cline SDK gateway; Vandit does not build an agent or reasoning engine. **Branch:** `feature/vandit-mcp-http`, created by Vandit from `integration/verity-v1` at checkpoint 0. **Owned:** `verity/mcp/**`, `verity/http/**`, transport tests and Vandit-owned fake service fixtures. No SQL, parser, ranking, Evidence construction or coverage evaluation belongs here.
