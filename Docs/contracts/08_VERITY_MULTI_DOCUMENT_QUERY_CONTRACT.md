# Multi-document query contract

**Owner:** Piyush for ranking; Atharv for evidence aggregation. **Consumers:** MCP, API, SDK, UI. **Version:** 1.0.0. There is no separate `search_multi_document` public function or MCP tool. `SearchRequest.document_ids` is the one multi-document selector: `null` searches all active documents; a nonempty UUID list restricts to those documents. This resolves the earlier plan's redundant tool suggestion.

`SearchRequest` may also filter `document_kinds` (`spec`, `general`), `chunk_kinds`, `limit` and `per_document_limit`. Filters are applied before branch top-k so one document cannot be hidden by candidates from excluded documents. Search ranks globally, then enforces `per_document_limit` if set. It may return fewer than `limit`; there is no per-document quota guarantee. `SearchResult.items` is a single ordered array of canonical Evidence objects. Each item includes `Citation.locator.source_id`, `document_id`, `version_id` and source path, so source identity survives aggregation. The UI may group this same array by `source_id` without changing rank. A `grouped` duplicate payload is forbidden in v1.

For a query across `payments-api.pdf`, `architecture.md` and `security-guidelines.pdf`, the request uses the three document UUIDs or `null` if the corpus contains only intended sources. A response might return Evidence from all three, with their original IDs, pages/sections and score. It does **not** promise one result from each source when a source is irrelevant. An empty source yields no item and can be inferred from the request plus returned IDs; the UI can display “No evidence found” for that document. `per_document_limit=2` caps each source's contribution at two after scoring. Reranking runs on the global fused pool before the cap and never merges provenance.

`compare_sources` is intentionally absent from v1 MCP/API/SDK. Cline can compare cited passages from `search_evidence`; an automated agree/conflict evaluator would be a new, evidence-backed contract. This avoids presenting “unassessed” as a comparison result. Cross-document retrieval is included; multi-hop reasoning and graph traversal are outside v1. This distinction reflects Mnemo's implemented cross-document retrieval versus its planned Phase 11 cross-document reasoning.
